## 文档约定（本仓库习惯）

- **规范类**（第一节）是**长效文档**，用 `vX.Y` 版本号，改代码前先读；状态写「现行 / 定稿 / 已落地」。
- **专项方案类**用「需求（**唯一依据**） + 落地方案」双文档：需求写**使用者要答出什么判断**，
  落地方案写**怎么实现 + 实测与勘误**。落地方案须长期维护「勘误」小节。
- **复盘/审计类**是**历史留档**，不再更新；其结论已并入规范或方案。
- 所有文档头部标注**版本 + 日期 + 状态**，便于判断时效。
