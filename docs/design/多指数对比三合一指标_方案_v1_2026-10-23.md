# 多指数对比 · 三合一指标升级 + 章节合并 方案 v1

> 日期：2026-10-23 夜
> 范围：`DomesticIndexView.vue`（前端）+ `env_service.py`（后端 domestic_compare 接口）
> 原则：可移植性——不新增表列、不重建物化表、不产生二次开发数据；全部复用已物化的 `env_index_tech_daily` 历史序列，查询时实时派生。

---

## 一、背景与目标

1. 用户希望「区间涨跌幅」补上**区间分位数**与**区间最大回撤**，三者**组合展示**，且**时间窗口可交互**（不写死）。
2. 用户希望把「指数总览」小节**并入「多指数对比」**，合成一个新的章节。

## 二、关键判断（实测结论，非估算）

- `env_index_tech_daily` 已物化：12 窗口涨跌幅历史序列（`win_1m/win_3m/...`）、回撤列（`max_dd_1y/3y/all`）。
- `env_metrics.py` 已有 `pct_rank()`（分位，稳定可复现）与 `window_return()`。
- ⇒ **无需新增表列、无需改 env_derive 重跑**。分位与回撤在 `domestic_compare` 接口内实时计算，历史序列从已物化表现取。

## 三、指标口径（写死，供验收）

| 指标 | 口径 | 数据来源 |
|---|---|---|
| 区间涨跌幅 | 末收盘 ÷ 区间首个有效收盘 − 1 | compare 已返回 `closes` |
| 区间最大回撤 | 区间内 `close / cummax − 1` 的最小值（最深处浮亏） | 对 `closes` 序列现算 |
| 区间分位 | 当前区间涨跌幅在「该指数近 3 年、按日滚动的**同窗口**涨跌幅序列」中的排位（pct_rank 口径，0=最低 100=最高）；<10% 或 >90% 视为历史极端 | 查 `env_index_tech_daily` 对应 win_* 列近 756 行 |

- 分位窗口用**近 3 年（756 交易日）**，避免未来函数：只取“截至区间末日前”的历史值参与排名。
- 自定义区间时，窗口天数按区间内实际交易日数反查最接近的固定窗口列；非标准天数用 `window_return(close, n)` 现算后与同 n 的历史滚动值比较。

## 四、交互设计

### 4.1 章节合并
「指数趋势与价格结构」章节内，将原三个小节合并为两个：

```
指数趋势与价格结构
 ├─ 多指数对比与总览   ← 合并（原「多指数对比」+「指数总览」）
 └─ 主图 K 线           ← 不变
```

合并后「多指数对比与总览」卡片内部顺序：多指数对比图（含窗口切换 + 模式切换 + 三合一条形）→ 指数总览表。

左侧导航「技术面分析」子项由 3 项变 2 项：`多指数对比与总览`、`指数趋势与价格结构`（K线主图）。锚点 id 相应调整。

### 4.2 区间统计条形 → 三合一指标卡
现有「区间统计条形」升级为「区间指标卡」，**窗口仍跟随多指数对比的窗口切换（3月/6月/1年/3年/自定义）**，一处选、三指标联动。

形态：每个所选指数一行，展示三列数值：

```
区间涨跌幅        区间分位(3年)        区间最大回撤
  -12.83%  ↘绿     12%  ↘极值金色        -18.5%  ↘绿
```

- 涨跌幅红涨绿跌（现有逻辑）；分位 <10% 或 >90% 用**金色**（与 PE 分位极值约定一致）；回撤绿色（回撤本是负值，用绿表示“下跌幅度”，中性色亦可，待定）。
- 保留“按涨跌幅排序”与“零轴居中发散式条形”的视觉（条形仍画涨跌幅，分位/回撤作为并行文本列）。

### 4.3 交互联动
- 窗口切换（3月/6月/1年/3年/自定义）→ 对比图 + 三合一卡 同时刷新（现有 loadCompare 已触发，扩展返回值即可）。
- 模式切换（净值/相对强弱）→ 只影响曲线，不影响三合一卡（三合一卡始终基于真实涨跌幅/回撤）。

## 五、实现改动清单

### 后端 `env_service.py`
`domestic_compare` 返回的每个 series 增加两字段：
- `max_drawdown`：区间内最大回撤(%)（对 closes 现算）
- `pctile`：区间涨跌幅的近 3 年分位（查 env_index_tech_daily 同窗口列历史序列，pct_rank）

（可选）新增轻量查询函数 `_window_pctile(code, win_col, value, end_date)`，返回分位。

### 前端 `DomesticIndexView.vue`
1. 章节/导航合并（4.1）
2. 区间统计条形 → 三合一卡（4.2），读取 series 新增的 `max_drawdown`、`pctile`
3. 口径说明更新

## 六、验收判据

- 后端接口：任一指数返回 `max_drawdown`/`pctile` 非空且数值合理（手工抽样对账 1~2 个指数）。
- 前端：切换窗口 → 三合一卡三列数值同步变化；分位极值金色高亮出现（构造或用真实数据）。
- 章节合并后导航锚点、滚动高亮正常；无运行时错误。
- 可移植性：换干净机器 + 空库，重跑 env_derive 后接口可出数（复用已物化列，无新增建表依赖）。

## 七、待用户拍板的点

1. 回撤配色：绿（视为“跌幅”）还是中性灰？（我建议绿，与涨跌红绿一致）
2. 三合一卡里「条形」是否保留？还是纯数字表格？（我建议保留条形画涨跌幅，分位/回撤作文本列）
