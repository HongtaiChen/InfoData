# 投资环境模块 设计方案 v0.1

> 日期：2026-10-18 ｜ 状态：**草案（待评审）**
> 目标：将现有「行情看板」（MarketView）升级为「**投资环境**」，**本期只建设「国内指数」子页**，按"国内指数 → 技术面/基本面分析 → 指标"三级组织，每个指标具备 **当前值 + 历史曲线 + 历史分位 + AI 结论** 四要素。其余子页（国际指数、市场氛围、政策、货币等）仅预留扩展位，不在本期范围。
> 遵循 design-first：本版只定方案，评审确认后出 v0.2 → 开发落地。

---

## 1. 需求还原：使用者视角的目标判断句

使用者是"开盘前/盘中做环境判断的个人投资者"，时间预算 3~5 分钟。本期打开「投资环境 → 国内指数」页，要在不外跳任何工具的情况下，答出以下判断句：

1. **今天国内指数安全吗？** —— 上证/沪深300/创业板/科创50 跌没跌超阈值？中期趋势（60/250 日线）偏强还是偏弱？量价配合健康吗？
2. **现在贵不贵？** —— 主要指数 PE/PB/股息率/ERP 处于历史什么分位，安全边际厚不厚？
3. **每一条结论为什么成立？** —— 每个判断都能下钻看到当前值、历史曲线、分位，以及 AI 给出的理由。

⇒ 整个模块的设计锚点：**每个指标 = 当前值 + 历史曲线 + 分位 + AI 结论**，四要素缺一不可。

---

## 2. 信息架构

```
投资环境（/environment，替换原「行情看板」入口）
└─ 1.1 国内指数            ← ★ 本期唯一建设项
     ├─ 指数范围说明（页面顶部折叠说明块，含样本指数清单与阈值定义）
     ├─ 技术面分析（1.1.2）
     └─ 基本面分析（1.1.3）

后续扩展位（本期不做，仅预留入口，避免将来重构）：
  1.2 国际指数 / 1.3 市场氛围 / 1.4 国内政策 / 1.5 国际环境 / 1.6 全球货币供应 / 1.7 国内货币供应
```

**为什么先只做国内指数**：它的数据基础最厚（日线 `dc_index_market`、估值 `index_valuation_daily`、成分股 `index_constituents`、财务摘要 `stock_financial_abstract_ths` 全有），且是使用者每天必看的第一张环境牌；先在这一块把"指标 → 当前值/曲线/分位/AI 结论"的**卡片模板与管线跑通**，后续 1.2~1.7 只需照此模板套用新数据源，边际成本最低。

**页面内不再设独立"环境总览"**：本期只有国内指数一页，总览功能内聚为页面顶部的**结论区**（每个指数一张红绿灯卡 + AI 一句话），多维度总览等 1.2~1.7 铺开后（v2）再单独成页。

## 3. 前端交互设计

### 3.1 路由与页面骨架

```
/environment            → DomesticIndexView.vue（国内指数，本期唯一页面）
                          /environment 直接落地国内指数页，不再设中间总览页
（后续扩展：/environment/global、/environment/sentiment 等，本期不建）
```

- 原侧边栏「行情看板」改名「投资环境」，`MarketView.vue` 的指数行情条/K 线能力**保留**，作为国内指数页顶部的"行情条"（复用已有 `IndexDetailDrawer` 下钻）。
- 页面内布局沿用 `analysis/` 组件族的 KPI 卡片 + 图表栅格（本期单页，暂不需 `n-tabs` 切换子页）。

### 3.2 页面内三层结构（以国内指数页为例）

```
┌ ① 指数范围说明（默认折叠的 n-alert，含样本指数、阈值口径、"AI 建议指数如何处理"）
├ ② 结论区（首屏可见，不滚动即读到）
│    每个指数一张"红绿灯卡"：综合评分 + 3~5 条结论句（技术面 N 条 / 基本面 N 条）
│    右上角 [🤖 重新生成 AI 结论] 按钮（带缓存时间标注）
├ ③ 技术面分析区（1.1.2）—— 按你的目录组织为三个指标组：
│    A. 指数趋势与价格结构
│       - 当日大幅下跌判定卡（阈值：上证>1% / 沪深300>1.5% / 创业板·科创>2% / 其他由 AI 建议阈值并标注）
│       - 多窗口涨跌幅矩阵：半月/一月/一个半月/两月/两个半月/三月/六月/一年/本年以来/本季度/本月/本周
│         （一张 12 列热力表，红涨绿跌；涨跌天数切换同一张表的第二视图）
│       - 均线位置卡：60 日/250 日线上方=偏强、下方=偏弱（含距均线 %）
│       - 量价关系卡：放量突破/缩量回调=健康 ✅；放量下跌/缩量反弹=无力 ⚠️（量用 20 日均量 ±30% 判定，口径入说明块）
│       - 技术指标卡：MACD（金叉死叉/背离）、RSI（超买>70/超卖<30）、布林带（上轨/下轨/中轨位置）
│       - 支撑/阻力位卡：近 250 日高低点 + 近期密集成交区（简化：250 日低点/高点 + 20 日高低点）
│    B. 指数波动与下行风险
│       - 最大回撤（近 1 年/近 3 年/历史全史）
│       - 年化波动率 / 下行波动率（60 日窗口）
│       - Beta（对沪深300，60 日窗口）
│       - 指数间相关性矩阵（近 120 日，热力图）
└ ④ 基本面分析区（1.1.3）
     A. 估值水平：PE-TTM 及分位 / PB 及分位 / 股息率及分位 / 股债收益差(ERP)及分位 / PB 离散度
     B. 盈利质量与成长：ROE 及稳定性 / 净利润增速 / 营收增速 / 经营性现金流（按指数成分股聚合）
     C. 宏观与政策环境：GDP/PMI、CPI/PPI、货币政策、财政政策、外部环境
        （本组以"读数卡 + AI 解读"为主，多为月频，不做曲线下钻，标注数据更新至 X 月）
```

### 3.3 指标卡片统一交互（核心组件 `EnvIndicatorCard`）

每个指标一张卡，四要素固定布局：

```
┌────────────────────────────────────────────┐
│ 指标名                    当前值  [分位徽章] │   ← 分位徽章：<20% 低(蓝) / 20-80% 中(灰) / >80% 高(琥珀)
│ ────────────────────────────────────────── │
│ [历史曲线：近 5 年，当前值高亮线 + 分位带]      │   ← 复用 DualLineTrend / 新增 HistoryCurve
│ ────────────────────────────────────────── │
│ 🤖 AI 结论：xxx（生成于 10-18 09:00）[↻]     │   ← 缓存结论，点 ↻ 重算
│ 📖 口径：xxx（TermTip 悬浮，复用现有组件）      │
└────────────────────────────────────────────┘
```

- **历史曲线交互**：悬停读值；点击某历史点 → 该点分位联动更新徽章；时间范围切换 1Y/3Y/5Y/全史。
- **多窗口矩阵类指标**（12 窗口涨跌幅/涨跌天数）：不做卡片，做整表 + 行列交换的切换（涨跌幅 ↔ 涨跌天数）。
- **AI 结论不自动阻塞页面**：卡片先渲染数据与曲线，AI 结论异步填充（骨架屏），失败显示"结论生成失败 [重试]"，不影响数据展示。
- **指数范围说明**：不单独成页，作为 ① 区折叠说明块（默认收起，首访自动展开一次），同时每个指标卡的 📖 口径 TermTip 与之互相引用。

### 3.4 复用与新增组件清单

| 类型 | 组件 | 说明 |
|---|---|---|
| 复用 | KpiCards / KpiHint / TermTip / DualLineTrend / HeatMatrix / RichText / IndexDetailDrawer / KLineChart | analysis 组件族直接复用 |
| 新增 | `EnvIndicatorCard.vue` | 四要素指标卡（本模块原子组件） |
| 新增 | `HistoryCurve.vue` | 历史曲线 + 分位带（可由 DualLineTrend 扩展） |
| 新增 | `MultiWindowMatrix.vue` | 12 窗口涨跌幅/天数矩阵 |
| 新增 | `TrafficLightCard.vue` | 红绿灯结论卡（国内指数页结论区） |
| 新增 | `EnvScopeNote.vue` | 指数范围说明折叠块 |

## 4. 后端服务设计

### 4.1 分层（沿用现有 controller → service → 仓储惯例）

```
backend/app/
├─ routers/env.py            # /api/environment/* 路由，只做参数解析与响应组装
├─ services/env_service.py   # 指标读取、分位计算编排、AI 结论调用与缓存
├─ services/env_metrics.py   # 纯计算层：均线/MACD/RSI/BOLL/回撤/波动率/Beta/相关性（可单测）
└─ collectors/env_derive.py  # 每日盘后物化任务（第 5 节）
```

### 4.2 API 清单（v1，聚焦国内指数）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/environment/domestic/indices` | 国内指数列表 + 当日涨跌 + 综合评分 + 结论区数据（替代总览页职责，收敛到本页） |
| GET | `/api/environment/domestic/indices/{code}/tech` | 该指数全部技术面指标（A/B 组，含多窗口矩阵数据） |
| GET | `/api/environment/domestic/indices/{code}/fundamental` | 该指数基本面指标（估值/盈利/宏观） |
| GET | `/api/environment/indicator-history` | 通用历史曲线：`?code=&metric=&window=`（供 EnvIndicatorCard） |
| GET/POST | `/api/environment/conclusion` | AI 结论读取 / 手动重新生成（POST，复用 ai.py 方舟通道） |
| GET | `/api/environment/scope-note` | 指数范围说明文本（含 AI 建议阈值的落库结果） |

设计要点：
- **分位计算在后端统一做**（历史全窗口分位查派生表，前端只收结果），口径集中在 `env_metrics.py`，杜绝前端复算。
- **多窗口涨跌幅**（12 个窗口）一次请求全量返回（`windows` 数组），不拆 12 个接口。
- **"其他指数跌超阈值按 AI 给建议"** 的落地方式：阈值表落库（见 5.2 `env_threshold`），对未手定阈值的指数，用「近 3 年日跌幅分布的 95 分位」算出建议阈值，存表并在范围说明块展示"该阈值由 AI 依据历史波动建议"。

### 4.3 AI 结论管线（复用现有方舟通道）

```
每日盘后 env_derive 物化完成
  → 链式触发 env_ai_conclusion 任务：按 (页面, 指数) 维度组装指标摘要 JSON
  → 方舟 AI 生成结构化结论（JSON：{verdict: 偏强/偏弱/中性, points: [...], confidence}）
  → 写 env_ai_conclusion（带 generated_at），前端读缓存
手动 [↻] → POST /conclusion → 立即重算该卡结论（限频：同卡 10 分钟内不重复调用）
```

- Prompt 约束：**只基于入库指标生成，禁止引用库外信息**；结论句必须能对应到具体指标（便于下钻溯源）。
- 宏观政策类（GDP/PMI/政策）允许 AI 结合新闻表（`news`）当日摘要做定性解读，但需在结论句标注信息来源（指标读数 / 新闻摘要）。

## 5. 数据落地

### 5.1 现有表复用映射（不重复采集）

| 需求 | 数据来源（已有） | 缺口 |
|---|---|---|
| 指数日线/成交量 | `dc_index_market` / `index_market_sync` | 无 |
| PE/PB/股息率/ERP | `index_valuation_daily` | 股息率分位、PB 离散度需派生 |
| 成分股名单 | `index_constituents` | 无 |
| 财务摘要（ROE/净利/营收/现金流） | `stock_financial_abstract_ths` | 需按指数聚合（派生） |
| 宏观读数（GDP/PMI/CPI/PPI） | `finance_calendar` 仅事件 | 🔴 **缺月度宏观序列表**（基本面 C 组依赖，需补源） |

### 5.2 新增表（2 张物化 + 2 张配置/缓存）

| 表 | 频率 | 内容 |
|---|---|---|
| `env_index_tech_daily` | 日频（盘后链式） | 每指数每天一行：12 窗口涨跌幅与涨跌天数、MA60/250 及上下方标记、量价状态(枚举)、MACD/RSI/BOLL 状态、支撑/阻力位、近1Y/3Y/全史回撤、年化/下行波动率、Beta、与沪深300相关性。**设计为"源值+状态枚举双列"**：状态列供红绿灯直接读，源值列供曲线与溯源 |
| `env_fundamental_daily` | 日频（估值部分）+ 季频（盈利部分） | PE/PB/股息率/ERP 及各自历史分位（滚动窗口内分位物化，避免每次现算全史）、PB 离散度、成分股聚合 ROE/净利增速/营收增速/经营现金流 |
| `env_threshold` | 配置 | 指数大幅下跌阈值表（手定 + AI 建议列 + 依据说明） |
| `env_ai_conclusion` | 缓存 | (scope, code, generated_at, verdict, points_json, model) |

> 注：`env_sentiment_daily`（成交集中度/换手/涨停/融资等）属"市场氛围"页，**移出本期**，待 1.3 落地时再建。

命名与规范：全部注册进 `table_meta`（分类「环境与结论」）；派生表都带 `data_source`/`updated_at`；物化任务进 `task_config` + `seed_task_config.py`，挂到 `market_style_sync → …` 链尾（受 `CHAIN_NOT_BEFORE` 约束），DQ 规则进 `seed_dq_rules.py`（freshness + 行数下限 + 枚举值域）。

### 5.3 🔴 补源缺口清单（本期需拍板）

| 缺口 | 优先级 | 建议来源 | 说明 |
|---|---|---|---|
| 月度宏观序列（GDP/PMI/CPI/PPI） | 高 | akshare macro_china 系列 | 基本面 C 组（宏观与政策环境）依赖 |
| 股息率历史分位 | 中 | 由 `index_valuation_daily` 现有列派生 | 若源已有股息率列则无新源 |
| 成分股财务聚合 | 中 | 由 `stock_financial_abstract_ths` 按成分股聚合 | 派生，无新源 |

### 5.4 可移植性硬要求（按项目标准执行）

- 两张物化表全部有**可重放幂等**的回填脚本（全史回填走 `scripts/`，参数固化进代码）；
- `env_threshold` 初始数据用 seed 脚本落库，不靠手工 INSERT；
- 不可重建部分（AI 结论缓存）显式标 `rebuild` 标签（丢失可再生成，不静默）。
