# 投资环境模块 设计方案 v0.2

> 日期：2026-10-18 ｜ 状态：**决策已定稿，进入开发** ✅
> 目标：将现有「行情看板」（MarketView）**替换**为「**投资环境**」，**本期只建设「国内指数」子页**。
> **设计导向**：页面**以呈现具体数据、指标与可对比的历史曲线为主，结论由观看者自行判断**，不做"红绿灯评分""AI 下结论"式的主观输出；**本期不做 AI 辅助解读**（E3）。
> 决策项 E1~E6 已全部定稿（见 §6）。

---

## 1. 需求还原：使用者视角

使用者是"开盘前/盘中做环境判断的个人投资者"，时间预算 3~5 分钟。打开「投资环境 → 国内指数」页，要能**自己快速读出数据、对照历史**，形成自己的判断：

1. **今天国内指数跌了多少、算不算"大幅下跌"？** —— 直接看到当日涨跌幅，并对照页面给出的阈值口径与历史分布自行判断。
2. **中期趋势处于什么位置？** —— 看到指数相对 60/250 日均线的位置、近 12 个时间窗口的涨跌表现与涨跌天数。
3. **现在贵不贵？** —— 看到 PE/PB/股息率/ERP 的**当前值与历史分位曲线**，自行判断安全边际。
4. **波动与风险有多大？** —— 看到最大回撤、波动率、Beta、指数间相关性的历史数据。

⇒ 设计锚点从"每个指标 = 当前值 + 曲线 + 分位 + AI 结论"改为：**每个指标 = 当前值 + 历史曲线 + 历史分位（+ 口径说明）**，**判断权交还观看者**。

## 2. 信息架构

```
投资环境（/environment，替换原「行情看板」入口）
└─ 1.1 国内指数            ← ★ 本期唯一建设项
     ├─ 指数范围说明（页面顶部折叠说明块：样本指数清单 + 阈值口径 + 指标口径）
     ├─ 技术面分析（1.1.2）
     └─ 基本面分析（1.1.3）

后续扩展位（本期不做，仅预留入口）：
  1.2 国际指数 / 1.3 市场氛围 / 1.4 国内政策 / 1.5 国际环境 / 1.6 全球货币供应 / 1.7 国内货币供应
```

**为什么先只做国内指数**：数据基础最厚（日线 `dc_index_market`、估值 `index_valuation_daily`、成分股 `index_constituents`、财务摘要 `stock_financial_abstract_ths` 全有），且是每天必看的第一张环境牌；先把"数据 + 图形"的**内容块模板跑通**，后续 1.2~1.7 照此模板套新数据源。

**本页不做结论区**：不设"环境总览 / 红绿灯 / AI 一句话总评"。页面就是数据与图形，判断由观看者完成。

## 3. 前端交互设计

### 3.1 路由与页面骨架

```
/environment            → DomesticIndexView.vue（国内指数，本期唯一页面）
（后续扩展：/environment/global、/environment/sentiment 等，本期不建）
```

- 原侧边栏「行情看板」**不保留，直接替换**为「投资环境」；原 `MarketView.vue` 的指数行情/K 线能力收敛为国内指数页顶部的"指数切换器 + 行情条"（指数切换器用 `index_profile` 全量 21 个指数，复用 `IndexDetailDrawer` 下钻）。
- **页面默认就是"一溜下来"的固定内容块流**（§3.2 的全部内容块，开箱即看，无需操作）。
- 页面右上角预留一个低调的「自定义分析」入口，指向**自由组装器**（见《投资环境_指标自由组装分析_补充方案》）。它只是**旁路**：不想用不打扰默认流，用了也只是把同样的指标重新组合、可另存为自己的视图，与固定内容块平级共存、互不覆盖。
- 页面主体是**上下滚动的内容块流**，按"技术面分析 → 基本面分析"两大区块组织，区块内再分指标组。

### 3.2 页面结构：以"内容块"为基本单元

核心设计：每个指标 = **一个内容块（IndicatorBlock）**，块内只放**数据 + 图形 + 口径**，不放结论。

```
┌ ⓪ 指数切换器（顶部，固定）：下拉选择指数（`index_profile` 全量 21 个，含上证/沪深300/创业板指/科创50/中证500 等），
│    切换后驱动下方全部内容块重新渲染；右侧展示当前指数当日涨跌幅与最新点位
│
├ ① 指数范围说明（折叠块：样本指数 / 阈值口径 / 指标口径，默认收起，首访展开一次）
│
├ ② 技术面分析（1.1.2）
│   A. 指数趋势与价格结构
│      · 当日涨跌幅块：当前指数当日涨跌幅 + 阈值参考线标注（上证 1% / 沪深300 1.5% / 创业板·科创 2% / 其他标注建议阈值）
│      · 多窗口涨跌幅块：12 窗口（半月/一月/一个半月/两月/两个半月/三月/六月/一年/本年/本季/本月/本周）涨跌幅热力矩阵，切换看"涨跌天数"
│      · 均线位置块：指数收盘价曲线叠加 60 日 / 250 日均线（KLineChart 扩展），标注当前价距两均线的百分比
│      · 量价关系块：成交量柱 + 价格线叠加，标注 20 日均量 ±30% 区间（放量/缩量一眼可读，不写"健康/无力"结论）
│      · 技术指标块：MACD（DIF/DEA/柱）、RSI（标注 70/30 参考线）、布林带（上/中/下轨）分 tab 展示
│      · 支撑阻力位块：近 250 日高低点 + 20 日高低点，在价格图上标注水平位
│   B. 指数波动与下行风险
│      · 最大回撤块：历史回撤曲线（水下曲线），标注近 1Y/3Y/全史最大回撤值
│      · 波动率块：年化波动率 / 下行波动率历史曲线（60 日滚动）
│      · Beta 块：对沪深300 的 60 日滚动 Beta 曲线（标 Beta=1 参考线）
│      · 相关性块：指数间 120 日相关性热力矩阵
│
└ ③ 基本面分析（1.1.3）
    A. 估值水平
       · PE-TTM 块：当前值 + 历史分位带曲线（当前值高亮，标注历史分位值）
       · PB 块：同上
       · 股息率块：同上
       · 股债收益差(ERP)块：当前值 + 历史曲线，标注历史均值参考线
       · PB 离散度块：历史序列曲线
    B. 盈利质量与成长
       · ROE 块：成分股聚合 ROE 及近 40 季度趋势曲线
       · 净利润增速 / 营收增速块：近 40 季度趋势曲线
       · 经营性现金流块：近 40 季度趋势曲线
    C. 宏观与政策环境（若 E6 决定本期纳入）
       · GDP/PMI/CPI/PPI 读数 + 历史曲线（月频，标注数据更新至 X 月）
```

### 3.3 内容块统一结构（核心组件 `IndicatorBlock`）

每个指标一个内容块，三要素固定布局：

```
┌──────────────────────────────────────────────┐
│ 指标名                            当前值 [分位] │  ← 分位仅作"位置参考"，不带主观色彩标签
│ ──────────────────────────────────────────── │
│ [主图形：历史曲线 / 矩阵 / 热力图 / 柱图]         │  ← 核心，占块内最大面积
│ ──────────────────────────────────────────── │
│ 📖 口径：xxx（TermTip 悬浮）  [时间范围 1Y/3Y/5Y/全史] │
└──────────────────────────────────────────────┘
```

- **分位呈现中性化**：分位只显示"当前值处于历史第 X% 分位"这一客观事实，**不配"低估/高估/偏强/偏弱"等定性词**；颜色只区分"极值区间 vs 中间区间"（如 <10% 或 >90% 高亮，其余中性灰），作为"此处值得多看一眼"的提示，而非结论。
- **历史曲线交互**：悬停读值；点击某历史点 → 该点分位联动显示；时间范围切换 1Y/3Y/5Y/全史。
- **口径说明**（TermTip + ① 区说明块）承担"这个数字怎么算、怎么读"的解释，取代原来"AI 结论"的位置——让观看者有据可依地自己判断。

### 3.4 复用与新增组件清单

|---|---|---|

## 4. 后端服务设计

### 4.1 分层

```
backend/app/
├─ routers/env.py            # /api/environment/* 路由，只做参数解析与响应组装
├─ services/env_service.py   # 指标读取、历史序列/分位编排（不含结论生成）
├─ services/env_metrics.py   # 纯计算层：均线/MACD/RSI/BOLL/回撤/波动率/Beta/相关性（可单测）
└─ collectors/env_derive.py  # 每日盘后物化任务（第 5 节）
```

### 4.2 API 清单（v1，聚焦国内指数，均为"读数据"型）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/environment/domestic/indices` | 国内指数列表 + 当日涨跌幅 |
| GET | `/api/environment/domestic/indices/{code}/tech` | 该指数全部技术面指标（A/B 组，含多窗口矩阵、均线/量价/技术指标/支撑阻力、回撤/波动率/Beta/相关性） |
| GET | `/api/environment/domestic/indices/{code}/fundamental` | 该指数基本面指标（估值分位序列 / 盈利成长 / 宏观） |
| GET | `/api/environment/indicator-history` | 通用历史曲线：`?code=&metric=&window=`（供 IndicatorBlock 主图形） |
| GET | `/api/environment/scope-note` | 指数范围说明文本（样本指数、阈值口径、指标口径） |

设计要点：
- **分位计算在后端统一做**（历史全窗口分位查派生表，前端只收数值），口径集中在 `env_metrics.py`，杜绝前端复算。
- **多窗口涨跌幅**（12 个窗口）一次请求全量返回（`windows` 数组），不拆 12 个接口。
- **阈值口径**：上证>1% / 沪深300>1.5% / 创业板·科创>2% 直接落库 `env_threshold`；未手定阈值的指数，用「近 3 年日跌幅 95 分位」算出**建议阈值**存表，并在说明块中标注"该阈值为按历史波动统计的建议值，仅供参考"——**不表述为"AI 判断"，只陈述为统计事实**。

### 4.3 数据管线（无 AI 环节）

```
每日盘后 env_derive 物化完成 → 前端读 env_index_tech_daily / env_fundamental_daily
```

- 本期不做 AI 辅助解读（E3），因此无 `/interpret` 接口、无 `env_ai_conclusion` 表。

## 5. 数据落地

### 5.1 现有表复用映射（不重复采集）

| 需求 | 数据来源（已有） | 缺口 |
|---|---|---|
| 指数日线/成交量 | `dc_index_market` / `index_market_sync` | 无 |
| PE/PB/股息率/ERP | `index_valuation_daily` | 股息率分位、PB 离散度需派生 |
| 成分股名单 | `index_constituents` | 无 |
| 财务摘要（ROE/净利/营收/现金流） | `stock_financial_abstract_ths` | 需按指数聚合（派生） |
| 宏观读数（GDP/PMI/CPI/PPI） | `finance_calendar` 仅事件 | 🔴 **缺月度宏观序列表**（基本面 C 组依赖，需补源） |

### 5.2 新增表（2 张物化 + 1 张配置）

| 表 | 频率 | 内容 |
|---|---|---|
| `env_index_tech_daily` | 日频（盘后链式） | 每指数每天一行：12 窗口涨跌幅与涨跌天数、MA60/250 及相对位置、量价状态(枚举)、MACD/RSI/BOLL 值、支撑/阻力位、近1Y/3Y/全史回撤、年化/下行波动率、Beta、与沪深300相关性。**存源值为主**，供曲线与图形渲染 |
| `env_fundamental_daily` | 日频（估值部分）+ 季频（盈利部分） | PE/PB/股息率/ERP 及各自历史分位（滚动窗口内分位物化，供分位带渲染）、PB 离散度、成分股聚合 ROE/净利增速/营收增速/经营现金流 |
| `env_threshold` | 配置 | 指数大幅下跌阈值表（手定 + 统计建议列 + 口径说明） |

> 已移除 v0.1 的 `env_ai_conclusion`（AI 结论缓存表）——E3 定稿本期不做 AI。
> `env_sentiment_daily`（成交集中度/换手/涨停/融资等）属"市场氛围"页，移出本期。

命名与规范：全部注册进 `table_meta`（分类「环境与结论」）；派生表都带 `data_source`/`updated_at`；物化任务进 `task_config` + `seed_task_config.py`，挂到 `market_style_sync → …` 链尾（受 `CHAIN_NOT_BEFORE` 约束），DQ 规则进 `seed_dq_rules.py`（freshness + 行数下限 + 枚举值域）。

### 5.3 🔴 补源缺口清单（E6 已定稿纳入宏观组）

| 缺口 | 优先级 | 建议来源 | 说明 |
|---|---|---|---|
| 月度宏观序列（GDP/PMI/CPI/PPI） | 高 | akshare macro_china 系列 | 基本面 C 组依赖，**本期需补源**（E6 定稿） |
| 股息率历史分位 | 中 | 由 `index_valuation_daily` 现有列派生 | 若源已有股息率列则无新源 |
| 成分股财务聚合（近 40 季度） | 中 | 由 `stock_financial_abstract_ths` 按成分股聚合 | 派生，无新源；⚠️ 需先核对该表历史深度是否覆盖 40 季度，不足则降级为"表内可得的最长季度数"并在口径标注 |

### 5.4 可移植性硬要求（按项目标准执行）

- 两张物化表全部有**可重放幂等**的回填脚本（全史回填走 `scripts/`，参数固化进代码）；
- `env_threshold` 初始数据用 seed 脚本落库，不靠手工 INSERT。
