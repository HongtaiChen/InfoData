## 1. 观测框架：四维 × 五区

货币流动性无法用单一指标刻画。本方案用**两个正交切面**定位每一个待观测指标：

### 1.1 四个维度（看什么）

| 维度 | 回答 | 典型指标 | 为什么必须有 |
|---|---|---|---|
| **① 价格** | 钱的价格（利率） | 政策利率、Shibor/DR007、国债收益率曲线 | 利率是估值分母；且**分位**比绝对值重要 |
| **② 数量** | 钱的总量与增速 | M0/M1/M2、社融、信贷、央行资产规模 | 价格只反映「边际供需」，数量反映「水位」 |
| **③ 央行行为** | 谁在放、谁在收、节奏 | 利率决议、准备金率、资产负债表扩张/收缩 | 流动性是**政策变量**，不是自然现象 |
| **④ 外部约束** | 跨境资金往哪走 | 汇率、美元指数、中外利差、外汇储备 | 开放经济下，国内流动性受外部硬约束 |

### 1.2 五个区域（看哪里）

**全球 → 美国 → 中国 → 日韩欧**。这不是并列关系，而是**传导链**：

```
   美国（全球美元流动性的源头：美联储 + 美债）
        │  美元指数 / 美债利率 = 全球风险资产的贴现率
        ▼
   全球（美元指数 + 主要央行方向共振）
        │
        ├──► 中国（本土政策主导，但受中美利差/汇率约束）
        │
        └──► 日韩欧（开放小型/中型经济体，对美元周期最敏感）
```

**为什么美国单独一层**：美元是全球流动性的**清算货币**。美联储的松紧直接决定全球美元供给，
其他央行在很大程度上是**跟随者或对冲者**（ECB/BOJ 的决策要减去美联储的影响才看得清）。
把美国和中国并列是新手常见的错——它们的**因果层级不同**。

### 1.3 「价 × 量」四象限（怎么下结论）

单看一个维度会误判。**价格与数量的组合**才是流动性的真实状态：

| | 数量扩张（量升） | 数量收缩（量降） |
|---|---|---|
| **价格下行（价降）** | 🟢 **主动宽松**：央行放水且信用在扩张，对权益最友好 | 🟡 **被动宽松 / 需求不足**：钱便宜但没人借 → 流动性陷阱风险，**警惕「宽松无效」** |
| **价格上行（价升）** | 🟠 **需求驱动**：资金需求旺盛，经济动能强 → 但对估值是逆风 | 🔴 **被动收紧**：央行收水或信用收缩 → 权益最危险组合 |

> ⚠️ 这张表是「货币流动性」模块的**判断骨架**——所有指标最终都是为了把当前状态放到这四个格子里。
> 只报数字不给格子，就又退化成「念 KPI」。

  外盘期货 `ak.futures_foreign_hist('DX')` 仍只返 13 行（2019 年陈年）。
  境外源：Yahoo `DX-Y.NYB` → **403**；FRED / investing.com → 读超时；marketwatch → 验证码；stooq → JS 挑战。
- **自算方案保留为交叉校验口径**（不是主口径了）：`currency_boc_safe` 含 ICE DXY 全部 6 个成分货币，按标准公式加权
  （采集器 `usd_index_sync`），2,380 行（2016-12-12 起）。
- 🔴 **「自算精度 ±0.1%」不成立（v0.3 自纠）**：v0.2 写着「修正后偏差 +0.085%」——
  那是**单点**且是**带符号**均值语境下的数字。回全史 2,380 个共有日重算：
  **|偏差| 中位 0.28% / p90 0.74% / p99 1.43% / 最大 2.29%**；
  带符号均值只有 +0.074%，**因正负相抵而严重低估离散度，不可当"精度"引用**。
- 🔴 **❌ 勘误（2026-09-25 落地时被实测推翻）**：v0.1 的「−3.09%、±3% 系统性偏离」是**标价法单位算错的假偏差**。
  根因：`currency_boc_safe` 宽表里**混用两种标价法** —— 美元等是**直接标价「人民币/100 外币」**（674.89 → ÷100 得 6.7489），
  瑞典克朗等是**间接标价「外币/100 人民币」**（147.31 → 100/v 得 0.67884），**只有这两种**；
  初版把 SEK 当直标 ⇒ USDSEK 算成 4.58（真值 9.94）⇒ 自算 DXY 偏低 3.3%，
  还**恰好伪装成**「中间价与市场价的固有偏离」。⇒ 「±3% 系统性偏离」的结论**不成立**。
- ✅ **偏差的真实成因是机制差（不是 bug、也不是精度）**：人民币中间价是**每日 9:15 的官方定盘价、基于前一交易日篮子**，

  到 09-28 反过来 —— 官方回落至 112.71、自算补涨到 113.97。
- ⇒ 口径标注**修正为**：**主口径 = 新浪官方日线（ICE 口径，可直接用绝对值）**；
  自算仅作**独立第二口径**，用于交叉校验（两条互比能立刻暴露单位错 —— 它正是抓出上述 SEK bug 的那张网），
  **不用于对外出数**。
- 补充：新浪 `hq.sinajs.cn/list=DINIW` 实测返回真实美元指数实时值（`101.2826`）→ 已每日累积为**标定基准**
  （表列 `dxy_snapshot`，自 2026-09-24 起），可长期复核偏差。⚠️ **不带 Referer 会 403**（v0.3 复测）。
- 🔒 **固化守护（三重）**：
  ① `dxy_sina_vs_calc_latest`（当日切片，`|偏差| > 2.5%` → 期望 0 行，**零假阳性、当日即触发**）；
  ② `dxy_sina_vs_calc`（全史上账，`|偏差| > 1.5%` → 实测 16 行，上账 ≤30）；
  ③ `dxy_vs_snapshot`（`ABS(dxy_calc − dxy_snapshot) > 1.5` → 期望 0 行）。

## 3. 「现状 / 变化 / 趋势 / 历史」四问的产品落地

用户明确要求：**现状、变化、趋势、历史**。这四问在每个维度上都要有落点，否则只是一个数字看板。

| 问 | 怎么算 | 前端落点 | 现状覆盖 |
|---|---|---|---|
| **现状** | 最新值 + 近一年分位 | KPI 数字 + 刻度条（`scale`） | ✅ 已有（`_kpi.scale`） |
| **变化** | 20 日 / 60 日绝对变化 | KPI `sub` 行（如「较 20 日前 +12bp」） | 🟡 部分有（`scale` 只给分位） |
| **趋势** | 连续同向期数（如「连升 5 期」）+ 拐点识别 | 判读条 `headline`（如「资金利率连续第 3 周回落」） | ❌ 缺 |
| **历史** | 极值 + 历史分位 + **历史类比** | 详情页专卡（如「当前形态类似 2013-06 / 2015-05」） | ❌ 缺（只有近一年分位） |

> **「历史类比」是最难也最有价值的一层**：算出当前（价格分位, 数量增速, 央行方向）三元组，
> 在历史上找最相似的时点，展示「当时之后 3/6 个月的 A 股表现」。
> ⚠️ 但这是**高风险的过度拟合**——样本少（中国货币周期约 3~4 轮）、伪相关多。
> **本方案不把它放进 v1**，列为 v2 候选（见 §6 决策项 D3）。

## 4. 实证算例（用现有数据**已经**能得出的结论）

> 这一节是方案的可行性证明：不是「理论上可以」，是**现在就能算出来**。

### 4.1 中美 10Y 利差（库里两列相减，零新增采集）

```
最近一期 2026-09-23:  中债10Y = 1.68%   美债10Y = 5.11%
中美利差 = −3.43pp
近 260 个交易日分位 = 0.4%   ← 近一年最窄（历史极值）
窗口: max −2.14 | min −3.43 | 中位 −2.48
```

**判读**：中美利差处于近一年**最窄**位置 ⇒ 人民币资产对海外资金的利差吸引力被压缩到极限，
构成资本外流与汇率贬值的**持续压力源**。这是「外部约束」维度最硬的一个数字，且**一行 SQL 就能算**。

### 4.2 M1−M2 剪刀差（可采，月度）

```
2026-08   M1 +4.1%   M2 +7.5%   剪刀差 −3.4pp
2026-07   M1 +4.0%   M2 +7.7%   剪刀差 −3.7pp
2026-06   M1 +4.0%   M2 +8.0%   剪刀差 −4.0pp
2025-09   M1 +7.2%   M2 +8.4%   剪刀差 −1.2pp   ← 一年前接近转正
```

**判读**：剪刀差从 2025-09 的 −1.2pp 走阔到 2026-06 的 −4.0pp、近两月略收窄（−3.4pp）。
资金活化度**过去一年在下降**（钱在往定期走，不是往活期走）⇒ 实体投资意愿偏弱。
近两月的边际收窄是**弱改善信号**，但仍在深度负值区。

### 4.3 央行资产负债表（可采，月度）

```
2026.8   总资产 498,567 亿   储备货币 401,814 亿   对其他存款性公司债权 213,399 亿   外汇 217,248 亿
2026.5   总资产 483,807 亿   储备货币 391,224 亿   对其他存款性公司债权 203,265 亿
```

**判读**：总资产 3 个月回升约 1.5 万亿，「对其他存款性公司债权」同步回升 1 万亿 ⇒
**央行在通过主动投放（MLF/逆回购）扩张资产负债表**，而非依赖外汇占款。
这与「M1−M2 剪刀差收窄」互相印证——**价×量四象限里落到「主动宽松」象限**。

### 4.4 美元指数（v0.3：官方日线主口径）

```
★主口径 官方日线（新浪 DINIW getDayKLine）= 101.26（2026-09-25）  近一年分位 95.6%  近 20 日 +1.57
        覆盖 1985-11-08 ~ 2026-09-25，10,573 行；与官方实时快照偏差 −0.004% ⇒ 可直接用绝对值
辅口径 自算（人民币中间价交叉汇率）      = 101.3532（2026-09-24）  与官方日线偏差 −0.089%
标定锚 实时快照（hq.sinajs.cn DINIW）    = 101.2826（2026-09-25）  与官方日线偏差 −0.025%
```

🔴 **勘误（两轮）**：
① v0.1 的「98.11 / 分位 91.2% / 偏差 −3.09%」全部**作废** —— 那是标价法漏除 100 的中间产物；
② v0.2 的「自算偏差 +0.085%」也不宜当精度引用 —— 它来自**单点**且是**带符号均值**语境，
   回全史 2,380 个共有日重算，**|偏差| 中位 0.28% / p90 0.74% / p99 1.43% / 最大 2.29%**
   （带符号均值 +0.074% 因正负相抵而低估离散度）。
⇒ **结论：自算不该当主口径**。v0.3 把主口径换成**官方日线**（更准、历史长 4.4 倍、起点早 31 年），
   自算降为**独立第二口径**（它的价值在"两条互比"这张网上，而不是在出数上）。

**判读**：美元处于近一年**高位（95.6% 分位）**且在走强 ⇒ 全球美元流动性偏紧，
与 4.1 的中美利差极窄**同向印证**（美元强 + 利差窄 = 新兴市场资金流出压力）。

> 4.1 + 4.4 的**交叉印证**就是「全球层」与「中国层」的联接点——
> 这也是当前卡片墙「互证」卡想做的事，只是目前只有 A 股内部维度。

| 现有模块 | 关系 | 边界（避免口径打架） |
|---|---|---|

## 9. 一个必须先解决的边界问题

**「资金温度」详情页已有一张「外部环境」卡（汇率 + 离岸人民币）**，
而本方案在「货币流动性」里也要放汇率与美元指数。**两处会打架**。

三种划法：

| 方案 | 划分依据 | 代价 |
|---|---|---|
| A) 按「变量类型」分 | 汇率归资金温度，利率/数量归货币流动性 | 逻辑清晰，但「美元指数」这个全球闸门会落空 |
| B) 按「区域」分 | 国内归货币流动性，跨境归资金温度 | 与现有「资金温度 = 汇率+发行+回购」结构冲突 |
| C) 按「因果位置」分 | **货币流动性管「钱的价格与数量」（因）；资金温度管「钱去哪了、多不多」（果）** | 需重写两边卡片的 `desc` 与判读条 |

**AI 建议 C**：货币流动性回答「央行与银行体系**投放/定价**了多少资金」，
资金温度回答「这些钱**有没有进入市场**」（基金发行 = 增量资金入场、回购 = 产业资本态度、汇率 = 外资流入）。
因果链更清楚，且不需要搬迁已有卡片。

### 9.1 ✅ 已落地（2026-09-25）

用户拍板方案 C，已固化到代码与契约：

| 落点 | 具体改动 |
|---|---|
| `registry.py` 契约 ⑩（新增） | **领域边界按「因果位置」划，不按数据源划**；给出判据（「给定条件」= 因 /「行为结果」= 果）与冲突实例（美元指数 vs 人民币汇率） |
| `registry.py` `money-cost` desc | 「回答**钱的价格与数量**（因）：价格、预期、政策、外部约束」 |
| `registry.py` `funding-temperature` desc | 「回答**钱去哪了、多不多**（果）：外部环境、增量资金、产业资本」 |
| `registry.py` `funding-temperature-fx` | `desc` 补「读的是跨境资金意愿的**结果**（果）；价格约束归货币流动性」；`question_text` 「外部资金环境松不松」→ **「外面的钱在进还是在出」** |
| `money_cost.py` `note` + docstring | 补「**领域边界**：本模块管钱的价格与数量（因）……归「资金温度」的是果」 |
