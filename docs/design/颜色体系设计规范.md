# InvestBuddy 颜色体系设计规范 v2.0（定稿）

> 版本：2026-09-05 · 状态：**已定稿（正式采纳）**
> 前置：v1.0（评审草案）已归档，本版承接其决策并纳入「金色强调」定位。
> 适用：InvestBuddy 全部前端模块 + 未来新页面；同时作为**同类投资/理财/行情类产品**的可复用配色资产。

---

## 0. 一句话理念

> **蓝为骨、金为魂、红绿只谈行情。**
> 深空蓝承担全部 UI 结构与管理语义（专业、可信、科技感）；
> 金色只给「系统产出的增值结果」（AI 洞察、策略收益、关键亮点数字）；
> 红涨绿跌是 A 股铁律，物理上只允许出现在行情数字与 K 线图上。

---

## 1. 设计原则（5 条，硬约束）

1. **行情语义唯一**
   红色 = 涨、绿色 = 跌。此二色**只**出现在行情数字 / K 线 / 行情指标上，绝不用于 UI 状态、按钮、成功提示。
2. **管理语义与行情解耦**
   成功/运行中/已连接 = **蓝（info）**；警告 = **琥珀**；失败 = **深红棕**；停用/手动/无数据 = **中性灰**。全站不出现「绿=成功」。
3. **金色是强调，不是结构**
   金色占比 ≤ 5–10%，只用于：AI 分析结论徽章、策略收益率数字、VIP/重要提示、Logo 点睛。禁止大面积金底、禁止金色正文小字。
4. **主题驱动，消灭硬编码**
   所有语义色经 naive-ui `themeOverrides` / CSS 变量一次注入，业务代码只写语义（`type="info"`、`var(--color-up)`），不写具体色值。
5. **克制即科技感**
   浅灰蓝底 + 白色卡片 + 细边框 + 充足留白；不堆大色块渐变、不滥用高饱和。

| 令牌 | 色值 | 语义 | 典型用途 |
|---|---|---|---|

| `text-2` | `#6B7280` | 次文字 | 描述、说明 |

### 防混淆对照（务必区分）

| 容易混淆的 | 正确理解 |
|---|---|
| 绿 `#14B143`（跌） ≠ naive `success` 绿 | naive success 语义在管理 UI 中一律改为 `info`（蓝） |
| 红 `#EF232A`（涨） ≠ 错误红 | 错误/失败用深红棕 `#791F1F`，两者在页面不会同屏出现于同一语义 |
| 金 `#C9A227`（增值强调） ≠ 琥珀 `#B45309`（警告） | 金用于「正面亮点」，琥珀用于「提醒注意」，色相与明度均不同 |

## 3. 完整色板（Ramp，供图表/标签/渐深场景取用）

### 蓝色系（主色扩展）

| 级 | 50 | 100 | 200 | 300 | 400 | 500 | 600 | 800 | 900 |
|---|---|---|---|---|---|---|---|---|---|
| 值 | `#E6F1FB` | `#CFE3F8` | `#B5D4F4` | `#85B7EB` | `#378ADD` | `#1E6FFF` | `#185FA5` | `#0C447C` | `#042C53` |

常用：50=浅底、100–200=浅描边/细分隔、400–500=hover、600=主色、800=深底文字、900=深色卡底。

### 金色系（强调点缀）

| 级 | 50 | 100 | 200 | 300 | 400 | 500 | 600 | 700 | 900 |
|---|---|---|---|---|---|---|---|---|---|
| 值 | `#FBF6E9` | `#F6EACB` | `#EEDC9E` | `#E3C565` | `#D4AF37` | `#C9A227` | `#A87E0E` | `#7A6410` | `#4A3D08` |

用法规则：
- 深蓝底（`#0C447C`/`#185FA5`）上的金字 → 用 `#D4AF37`/`#E3C565`（如 AI 徽章、深色 KPI 卡数字）。
- 白底上的金色数字 → **只用 ≥700 级**（`#7A6410`，对比度 ≈ 4.9:1），且字号 ≥ 20px 加粗；否则改回蓝色主色。
- 金色永不用于：正文、按钮底色、整块卡片背景。

### 行情色系（唯一允许红绿的色域）

| 用途 | 涨 | 跌 | 平 |
|---|---|---|---|
| 主文字/阳线 | `#EF232A` | `#14B143` | `#909399` |
| 浅底 chip | `#FDEBEC` | `#E6F7EE` | `#F0F0F0` |
| 强调（大数字） | `#C62828` | `#0E8C35` | — |

### 中性色系

| 用途 | 值 |
|---|---|
| 页面底 | `#F5F7FA` |
| 卡片 | `#FFFFFF` |
| 边框 | `#D4D7DE` / hover `#B8BEC9` |
| 文字三级 | `#1F2937` / `#6B7280` / `#9CA3AF` |
| 停用/手动 | `#5F5E5A` |

## 5. 组件配色细则

### 5.1 状态语义（全局对照表）

| 业务状态 | naive type | 颜色 | 反例（禁止） |
|---|---|---|---|
| 运行中/已连接/已分析/已同步 | `info` | 蓝 `#185FA5` | ~~success 绿~~ |
| 保存/执行/分析 主操作 | `primary` | 蓝 `#185FA5` | ~~绿主按钮~~ |
| 格式错误/延迟/占位 | `warning` | 琥珀 `#B45309` | ~~naive 默认橙红 error~~ |
| 任务失败/接口错误 | `error` | 深红棕 `#791F1F` | ~~亮红（会像涨停）~~ |
| 停用/手动/空 | 自定义灰 | `#5F5E5A` | 绿/蓝易被读成「正常」 |
| AI 洞察/收益亮点 | 自定义金 | `#C9A227`/深底 `#D4AF37` | 金色不得用于错误态 |

### 5.2 涨跌数字（行情内）

```html
<!-- 涨跌 chip：红涨绿跌 + 浅底，背景不刺眼 -->
<span class="price-chip up">+3.21%</span>
<span class="price-chip down">-1.85%</span>
<span class="price-chip flat">0.00%</span>
```

```css
.price-chip { padding: 1px 8px; border-radius: 4px; font-size: 12px; }
.up   { color: #EF232A; background: #FDEBEC; }
.down { color: #14B143; background: #E6F7EE; }
.flat { color: #909399; background: #F0F0F0; }
```

### 5.3 金色强调（AI 洞察 / 亮点数字）

| 场景 | 实现 |
|---|---|
| 深蓝卡片上的 AI 徽章 | 底 `#0C447C`、字/描边 `#D4AF37` |
| 白底大号收益数字（≥20px bold） | 文字 `#7A6410`（AA 达标） |
| 列表行内「AI」小标记 | `#C9A227` 圆点 + 灰字说明 |
| 金色背景块 | **禁用**（可用 `#FBF6E9` 浅金底 + `#7A6410` 深金字代替） |

## 6. 落地技术方案（可直接复制）

### 6.1 naive-ui 主题覆盖（建 `frontend/src/theme.ts`，在 App 外层挂 `NConfigProvider`）

```ts
import type { GlobalThemeOverrides } from 'naive-ui'

export const themeOverrides: GlobalThemeOverrides = {
  common: {
    primaryColor: '#185FA5',
    primaryColorHover: '#1E6FFF',
    primaryColorPressed: '#0C447C',
    primaryColorSuppl: '#1E6FFF',
    infoColor: '#185FA5',
    infoColorHover: '#1E6FFF',
    warningColor: '#B45309',
    errorColor: '#791F1F',
    bodyColor: '#F5F7FA',
    cardColor: '#FFFFFF',
    modalColor: '#FFFFFF',
    popoverColor: '#FFFFFF',
    borderColor: '#D4D7DE',
    dividerColor: '#E7E9EE',
    textColor1: '#1F2937',
    textColor2: '#6B7280',
    textColor3: '#9CA3AF',
    // 关键：success 映射为蓝，从源头消灭管理 UI 的绿
    successColor: '#185FA5',
    successColorHover: '#1E6FFF',
    successColorPressed: '#0C447C',
  },
  Menu: { itemTextColorActive: '#185FA5', itemIconColorActive: '#185FA5' },
  Button: { fontWeight: '500' },
}
```

> 说明：`successColor` 覆盖为蓝是**双保险**——即使有人误写 `type="success"`，渲染结果仍是蓝，不会出现「绿=跌」与「绿=成功」同屏混淆。

### 6.2 全局行情色 CSS 变量（`style.css`）

```css
:root {
  --color-up: #EF232A;   --color-up-bg: #FDEBEC;
  --color-down: #14B143; --color-down-bg: #E6F7EE;
  --color-flat: #909399;
  --color-primary: #185FA5; --color-primary-hover: #1E6FFF;
  --color-gold: #C9A227;    --color-gold-deep: #7A6410;
}
```

### 6.3 迁移口诀

> **凡「成功/正常/运行中」→ `info`；凡「主操作」→ `primary`；凡「停用/手动」→ 灰；行情红绿只进数字与 K 线。**

### 6.4 落地顺序

1. P0：建 `theme.ts` + 挂 `NConfigProvider` → 全站按钮/菜单/标签即时变蓝。
2. P0：MainLayout Logo、JobsView「调度器运行中」等 success→info。
3. P1：CalendarView / NewsView 状态与来源 tag。
4. P2：AnalysisView / SettingsView 连接态 + AI 结论上金。
5. 收尾：`grep #18a058` 与 `type="success"` 全站归零；截图逐页比对。

## 7. 其他项目借鉴指南（决策树）

**要不要用「蓝骨金魂」体系？**

1. 项目是 **行情 / 投研 / 量化 / 交易** 类 → 是 → 直接采用本规范（红绿已预留给行情）。
2. 是 **理财 / 银行 / 贵金属** 类 → 可把蓝主调换成品牌深色，但**红涨绿跌约束改为产品自身的涨跌约定**；金色可适当加大（但 ≤20%）。
3. 是**通用工具/后台**（无行情语义）→ 本规范去掉 §3 行情色即可，蓝主金辅同样成立。
4. 通用管理后台不想用金 → 只用蓝色语义体系（primary=蓝、成功=info 蓝或 teal、错误=深红棕），依然比「默认绿」专业。

**可直接带走的 5 条经验**

- naive-ui/Element/AntD 默认主题色通常是绿或品牌绿 → **先查默认 primaryColor，99% 的"为什么全站是绿的"都是没配主题**。
- 「成功=绿」与「行情跌=绿」冲突是投资产品的第一配色事故 → 管理语义统一蓝。
- 金色是好强调色但对比度差 → 白底必须用深金（≥ #7A6410 级）且大字号；深底才可用亮金。
- 错误色用深红棕 `#791F1F`，和涨红 `#EF232A` 拉开明度差，避免「报错像涨停」。
- 颜色改一处还是改百处 → 取决于有没有 token 层：先建 token，再谈改色。
