# Plan: InfoData项目重构 - 定时任务调度系统

## 1. 技术选型决策

### 1.1 调度框架
**选择**: APScheduler
**理由**:
1. 轻量级，适合单机部署（用户确认单机部署即可）
2. 支持cron表达式和间隔调度
3. 内置持久化支持（SQLAlchemy）
4. 与现有Python技术栈兼容
5. 学习成本低，易于维护
6. 不需要分布式部署，APScheduler完全满足需求

**分布式部署**: 不需要，单机部署足够

### 1.2 数据库
**选择**: MySQL + SQLite
**理由**:
1. 主数据继续使用MySQL
2. 任务执行记录使用MySQL的独立表
3. 开发环境使用SQLite简化部署
4. 保持与现有系统兼容

### 1.3 数据源确认
**选择**: AKShare + Tushare
**确认信息**:
1. **Tushare**: GitHub 14,642星，最后更新2026-03-20，非常活跃稳定
2. **AKShare**: 开源金融数据接口库，持续更新维护
3. **权威性**: 两个数据源都权威稳定，无需付费备用数据源
4. **稳定性**: 足够稳定，满足生产环境需求

### 1.4 监控告警
**选择**: 内置监控 + 简单告警
**理由**:
1. 初期需求简单，不需要复杂监控系统
2. 支持邮件和Webhook告警
3. 后续可集成Prometheus

#### 2.2.1 调度管理器 (SchedulerManager)
```python
class SchedulerManager:
    """调度管理器"""
    
    def __init__(self, config: Config):
        self.scheduler = BackgroundScheduler()
        self.config = config
        self.tasks = {}
        
    def start(self):
        """启动调度器"""
        
    def stop(self):
        """停止调度器"""
        
    def add_task(self, task_class, schedule):
        """添加任务"""
        
    def get_status(self):
        """获取调度器状态"""
        
    def trigger_task(self, task_name):
        """手动触发任务"""
```

#### 2.2.2 任务基类 (BaseTask)
```python
class BaseTask(ABC):
    """任务基类"""
    
    def __init__(self, name: str, config: Dict):
        self.name = name
        self.config = config
        self.logger = logging.getLogger(f"task.{name}")
        
    @abstractmethod
    def execute(self) -> TaskResult:
        """执行任务"""
        
    def validate(self) -> bool:
        """验证任务配置"""
        
    def cleanup(self):
        """清理资源"""
        
    def on_success(self, result: TaskResult):
        """成功回调"""
        
    def on_failure(self, error: Exception):
        """失败回调"""
```

## 4. 技术决策细节

### 4.1 配置管理
- **格式**: YAML + 环境变量
- **热更新**: 支持配置文件修改后自动重载
- **验证**: 使用Pydantic进行配置验证
- **加密**: 敏感信息使用环境变量或密钥管理服务

### 4.2 错误处理
- **重试策略**: 指数退避重试，最多3次
- **错误分类**: 网络错误、数据错误、系统错误、业务错误
- **错误恢复**: 自动恢复 + 人工干预
- **错误通知**: 分级告警，紧急错误立即通知

### 4.3 性能优化
- **数据库连接池**: 使用SQLAlchemy连接池
- **批量操作**: 数据批量插入，减少数据库交互
- **缓存策略**: 频繁访问的数据缓存
- **并发控制**: 限制并发任务数，避免资源竞争
- **时间约束**: 日度数据更新最晚22:00前完成
- **准确性要求**: 数据准确性99.99%

### 4.4 安全考虑
- **敏感数据**: 环境变量存储，不在代码中硬编码
- **API安全**: API密钥轮换，访问频率限制
- **数据安全**: 数据传输加密，数据存储加密
- **审计日志**: 所有操作记录审计日志
