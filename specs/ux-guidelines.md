# InfoData - 用户体验指南

## 1. 设计原则

### 1.1 以用户为中心
- **用户需求优先**：所有功能设计围绕用户实际需求
- **简洁高效**：界面简洁，操作高效，减少用户认知负担
- **一致性**：保持界面和交互的一致性，降低学习成本
- **反馈及时**：操作有明确反馈，状态清晰可见

### 1.2 金融数据特殊性
- **数据准确性**：金融数据展示必须准确无误
- **实时性**：重要数据实时更新，延迟明确标示
- **可追溯性**：数据来源和更新时间清晰标注
- **风险提示**：投资风险和数据不确定性明确提示

### 1.3 无障碍设计
- **可访问性**：支持屏幕阅读器，色盲友好配色
- **响应式设计**：适配不同设备和屏幕尺寸
- **国际化**：支持多语言，考虑文化差异
- **包容性**：考虑不同技能水平的用户

## 2. 视觉设计指南

### 2.1 色彩方案
**主色调**：
- **主色**：深蓝色 (#2C3E50) - 代表专业和信任
- **辅色**：绿色 (#27AE60) - 代表增长和正面
- **强调色**：橙色 (#E67E22) - 代表警告和重要
- **背景色**：浅灰色 (#F8F9FA) - 舒适阅读背景

**语义颜色**：
- **成功**：绿色 (#27AE60)
- **警告**：橙色 (#E67E22)
- **错误**：红色 (#E74C3C)
- **信息**：蓝色 (#3498DB)
- **中性**：灰色 (#95A5A6)

**金融数据颜色约定**：
- **上涨/积极**：绿色 (#27AE60)
- **下跌/消极**：红色 (#E74C3C)
- **中性/持平**：灰色 (#95A5A6)
- **高亮/重要**：金色 (#F1C40F)

### 2.2 字体规范
**英文字体**：
- **主要字体**：Inter 或 Roboto (无衬线字体)
- **代码字体**：Monaco 或 Consolas (等宽字体)

**中文字体**：
- **主要字体**：思源黑体 或 苹方字体
- **备选字体**：微软雅黑

**字体大小**：
- **标题1**：24px (页面标题)
- **标题2**：20px (区块标题)
- **标题3**：16px (小节标题)
- **正文**：14px (主要阅读文本)
- **小字**：12px (辅助信息、标签)
- **极小字**：10px (图表标签、脚注)

### 2.3 间距和布局
**间距系统**：
- **基准单位**：8px
- **小间距**：4px (内部元素)
- **中间距**：8px (相邻元素)
- **大间距**：16px (区块间距)
- **特大间距**：24px (页面区块)

**布局网格**：
- **网格系统**：12列响应式网格
- **断点**：
  - 移动端：< 768px (单列布局)
  - 平板端：768px-1024px (两列布局)
  - 桌面端：> 1024px (多列布局)
- **容器宽度**：
  - 最大宽度：1200px (桌面端)
  - 内边距：24px (移动端16px)

## 3. 交互设计指南

### 3.1 导航设计
**主导航**：
- 固定顶部导航栏
- 面包屑导航显示当前位置
- 侧边栏导航用于功能模块
- 页脚导航提供辅助链接

**搜索功能**：
- 全局搜索框，支持智能提示
- 高级搜索选项可展开
- 搜索结果分类显示
- 搜索历史和建议

**快速操作**：
- 浮动操作按钮(FAB)用于主要操作
- 上下文菜单提供相关操作
- 键盘快捷键支持

### 3.2 表单设计
**输入字段**：
- 清晰标签和占位符文本
- 实时验证和错误提示
- 必填字段明确标识
- 输入辅助(自动完成、建议)

**按钮设计**：
- **主要按钮**：深蓝色背景，用于主要操作
- **次要按钮**：边框按钮，用于次要操作
- **危险按钮**：红色背景，用于删除等危险操作
- **按钮状态**：正常、悬停、激活、禁用
- **按钮大小**：大(48px)、中(40px)、小(32px)

**表单布局**：
- 单列布局，避免多列混淆
- 相关字段分组显示
- 长表单分步骤或分页
- 保存进度和草稿功能

### 3.3 反馈机制
**加载状态**：
- 骨架屏占位符
- 进度条显示加载进度
- 加载动画避免用户焦虑
- 预估加载时间显示

**操作反馈**：
- **成功提示**：绿色Toast消息，3秒自动消失
- **错误提示**：红色Toast消息，需手动关闭
- **警告提示**：橙色Toast消息，5秒自动消失
- **信息提示**：蓝色Toast消息，3秒自动消失

**状态指示**：
- 实时状态更新
- 操作进度显示
- 网络连接状态
- 数据同步状态

## 4. 数据展示指南

### 4.1 表格设计
**基础表格**：
- 斑马纹行提高可读性
- 表头固定，支持排序
- 每页显示20-50行数据
- 列宽自适应内容

**表格功能**：
- 列筛选和搜索
- 列显示/隐藏控制
- 数据导出功能(CSV、Excel)
- 行选择和多选操作

**金融数据表格**：
- 数值右对齐，文本左对齐
- 货币格式统一显示(¥1,234.56)
- 涨跌用颜色和箭头标示
- 重要数据加粗或高亮

### 4.2 图表设计
**图表类型选择**：
- **折线图**：趋势分析，时间序列数据
- **柱状图**：数据对比，分类数据
- **饼图**：比例分布，组成分析
- **散点图**：相关性分析，分布情况
- **K线图**：股票价格变化

**图表样式**：
- 清晰标题和图例
- 坐标轴标签清晰可读
- 数据点悬停显示详细信息
- 支持图表缩放和平移

**金融图表特殊要求**：
- 时间轴显示明确时间段
- 价格坐标轴合理刻度
- 成交量与价格联动显示
- 技术指标叠加显示

### 4.3 卡片设计
**数据卡片**：
- 卡片化布局，信息分组
- 统一卡片尺寸和边距
- 卡片内信息层次清晰
- 交互式卡片支持展开/收起

**指标卡片**：
- 关键指标突出显示
- 趋势箭头和变化百分比
- 对比数据和历史数据
- 数据来源和时间戳

## 5. 金融数据特殊设计

### 5.1 数据准确性设计
- **数据源标识**：明确显示数据来源
- **更新时间**：精确到秒的数据更新时间
- **数据状态**：实时/延迟/历史数据标识
- **刷新机制**：手动刷新和自动刷新选项

### 5.2 风险提示设计
- **风险等级**：高风险数据红色警告
- **免责声明**：必要风险提示和免责声明
- **数据说明**：数据计算方法和局限性说明
- **投资建议**：明确标注是否为投资建议

### 5.3 实时数据设计
- **更新频率**：明确数据更新频率
- **延迟提示**：网络延迟或数据延迟提示
- **实时推送**：WebSocket实时数据推送
- **数据缓存**：离线时显示缓存数据并提示
